# Ana Tele Mobile — UX prototype

Mobile-first прототип урока татарского языка. Текущая версия реализует путь:

`Учёба → 21 упражнение → Урок завершён → Модуль завершён`.

## Быстрый старт

```bash
npm install
npm run dev
```

Локальный адрес: `http://127.0.0.1:5173/`.

Production-сборка:

```bash
npm run build
```

Готовые статические файлы появляются в `dist/`. Для обычного статического хостинга загружайте **содержимое** `dist`, чтобы `index.html` находился в корне сайта.

## Основные файлы

- `src/App.tsx` — навигация, состояния урока и компоненты упражнений.
- `src/lessonData.ts` — контент и конфигурация 21 упражнения.
- `src/styles.css` — весь визуальный слой, анимации и мобильная адаптация.
- `public/assets/` — изображения, персонажи, SVG и аудио.
- `docs/` — продуктовые и технические документы.
